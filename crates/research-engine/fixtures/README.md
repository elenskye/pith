# 合成夹具

全部是虚构的：地名（示例市、样本市）、机构（示例市统计局、示例大学劳动经济研究所、示例招聘平台、示例日报）和数字都不对应任何真实统计。

- `text/`：各个来源取出来的正文（引擎自己的测试用，不经过下载和取正文）。原始格式的同一批来源（HTML、CSV、XLSX、PDF）在 `src-tauri/fixtures/research/`，两边的文字要保持一致：模型回复里的摘录要在两边都逐字找得到。
- `replies/`：录制的模型回复（计划、各来源的摘录）。结论由 `src/fixture.rs` 里的模拟模型按事实表生成。
- 第二轮（重查）：`*-r2` 是同一个网址更新后的内容，另有一个新来源和一个消失的来源。
