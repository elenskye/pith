# 0039 · 联网：对话里搜、取回原文、引用网页、存进知识库（1.1.0 第 4 期）

- 日期：2026-11-26
- 状态：现行。落实 `0034` 1.1.0 第 4 期、`0035`「插件」里的「联网」
- 来源：v0.3 事实调查的搜索和下载（`0020`、`0022`、`0023`：Claude 网页搜索、Tavily、本机下载、快照、Claude 网页抓取后备）；v0.4 的 OpenAI 网页搜索（`concept/responses.rs`）；`0038` 的引用编号

## 工具（插件「联网」）

- `web_search(query, limit)`：返回几条结果的标题、网站、网址、摘要。摘要只是线索，规矩里写着「只看摘要不算核实过」。
- `web_fetch(url, from)`：取回一页（网页或 PDF 等，正文提取沿用 v0.3 的 `content`），存快照，正文切块（和知识库的切法一样），每块一个编号 `[W12]`；一次给约 6000 token，太长的 `from` 写上次结尾给的编号接着读。同一个网址、同样的内容只存一份（再取还是那些编号）。
- 两个都算「只读」：一批里能并行，子代理也能用。

## 搜索用谁的

- **跟着这一回的模型**：Anthropic 用 Claude 网页搜索（便宜的一档 Haiku 5.5 搜一次）、OpenAI 用 Responses 的网页搜索（均衡档）、Google（API Key）和 Vertex AI 用 Gemini 的 Google 搜索（便宜的一档，grounding）。DeepSeek 没有自带的，用 Tavily。
- 那一家的用不了（没密钥、Vertex 没登录）：有 Tavily 用 Tavily；也没有，就借别家有密钥的自带搜索（Anthropic → OpenAI → Google → Vertex），结果里说一声。什么都没有：工具回一句「去设置 › 模型与费用 填一把」。
- 为什么不让主模型自己搜（把搜索当成主请求里的服务端工具）：四家的服务端搜索格式、回放规矩、引用方式各不一样，要把它们都塞进网关的中立消息里；而单独一次便宜的搜索调用，四家拿到的是同一种结果、同一套工具和编号，换模型不影响对话的回放。代价是每次搜索多一次小调用（几分钱以内）。
- 密钥只在模型第一次用联网工具时才读（正式版不会为了没用到的工具去碰钥匙串）。

## 取回

- 本机下载（v0.3 的下载器：不下本机和内网、自己跟跳转、每一跳都检查、同一站点间隔 1.5 秒、类型按内容判断、User-Agent 只有 `Pith/版本`）。失败了、有 Anthropic 密钥就改用 Claude 网页抓取（`0023`），页面上标明。
- 快照在 `数据目录/web/`（和事实调查、概念研究的分开，不被它们的清理删掉），只读、按 SHA-256 同内容一份；正文在同名 `.txt`。
- **migration 0012**：`web_pages`（网址、跳转后的网址、标题、快照、类型、怎么取回的、哪段对话、什么时候）、`web_blocks`（块：小标题、正文）。

## 引用和存进知识库

- 回答里的 `[W12]` 和 `[P123]` 一起编号（`kb::cite`）。网页的页边注：网页、标题、网站 · 小标题 · 取于哪天、那一块原文；「打开网页」用系统浏览器打开；「存进知识库」建一份「网页快照」材料（来源 `web_page` + 这一页的 id），块就是那一页的块（能检索、能引用），存过的变成「知识库里」。存进哪个库：这段对话勾的第一个库，没勾就第一个库（没有就建「随手存」）。
- 交付卡存进知识库的正文：出处里网页写标题、网站、日子和网址。

## 记账

- 搜索、网页抓取都按最坏情况查月上限，用途记 `chat_web`（「联网」），带着对话的 uid（这一段对话花了多少算得上）。
- Gemini 的 Google 搜索按每次 $0.035 记（各型号的搜索计费不一样，宁多勿少），以账单为准；Claude 网页搜索 $0.01 一次、Tavily 一点 $0.008，照 v0.3。

## 开发版

- 模拟的搜索和合成的网页（事实调查的「示例市」），不联网、不花钱；开发版的模拟脑子遇到「网上、最新、联网、查一下、新闻」先搜、再取回第一条、引用里面的一段。
