## 修了的（这一期的提交里）

1. **回答丢了**：DeepSeek 把整篇回答和交付卡写在同一轮，最后一轮只说「上面放了交付卡」；以前把跟着任何工具调用的文字都当过程话（「我查一下」）清掉，只留最后一句。现在只有跟着查、读、算（只读的工具）写的才算过程话，跟着交付卡、问题卡写的是回答，留着；正在写的样子也一样（`harness::answer_text`）。
2. **Book IV、V 都成了第 570 页**（DeepSeek 在回答里指出来的）：Penguin 版第二卷的 EPUB 里一个页码标记都没有，解析器把第一卷最后的页码一直往下带。现在离上一个页码标记超过约两页的字（`STALE_PAGE`，中文一个字算 3）就当作没有页码；解析器版本 `concept-text-3`。**已存的书要「重新解析」一次**才改过来，知识库里那份跟着重抄（第 3 期接好的），段落编号不变。
3. **Google 的新密钥认不出**：2026 年起新建的 Google API Key 是 `AQ.` 开头（站主的就是），以前只认 `AIza`，设置里填不进去。两种都认了。
4. **中译本的段落标成「原文」**：书是译本时页边注写「译文」。
5. **几处模型常用的写法**：单个换行隔开的小标题、列表、普通行（以前整块当一段、列表的「- 」露出来）；`>` 引文；`[文字](网址)`（点了用浏览器打开）；引用写成范围 `[P12–P15]`（换成 `[a]–[b]`）。
6. **中途断了的提示**：Gemini 写到一半 503，已经生成的部分记了账，提示却说「这次没有产生费用」；改成「中途断了，已经生成的部分按估计记进了用量」。
