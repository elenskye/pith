## 采纳的工程选择（云端定的）

细节见 `docs/architecture.md`「v0.4 概念研究」和 `crates/concept-engine/README.md`。

1. XHTML 用自己写的容错读取（roxmltree 遇到 `&nbsp;` 报错；scraper 把 XHTML 的自闭合 `<a id="page_110"/>` 当成没关上的标签）。
2. 页码来源依次是 EPUB 3 page-list、ncx pageList、`page-map.xml`、正文里的分页锚点；Penguin 的 `page-map.xml` 写的是 calibre 拆分前的文件名，按 `<名>_split_*` 找回来（实际用的是 ncx pageList）。
3. 角色不看 class 名：先按目录文字分单元（篇、章、节、导读、注释、前后附；导读先认），再逐块认标题、旁注（≤ 160 字的 `blockquote`）、注释区（「［N］」开头且被注释引用指向）。注释的引用标记不进正文。
4. 引用名全书唯一：`I.i.3`、`I.i.3 旁注`、`I.i 注 1`、`Intro.5`、PDF 只有段 `5`；锚到译本的写 `译:I.i 注 1`。
5. 对齐按（篇, 章）配对，段数相同才一段对一段。
6. 段落检索：`search.concept_paras`（FTS5），只收正文、旁注、注释、导读；和主库对不上就重建。中文词搜英文原著：先搜对齐的中译，再映射回原著。
7. 概念研究自己的折叠：v0.3 的折叠 + 弯直引号、撇号样式、拉丁字母大小写。
8. 核对：原文句的文字必须就是引文，只能挂原著正文段；他人要有来源或挂译本的旁注、注释、导读；解释挂的段落不存在或引文找不到就去掉锚点、标「没挂上原文」；推演的前提按原文核对；一句不剩的卡片不要，关系两头都要在。
9. 技能元数据是 YAML 小子集（README 有格式），多一个键 `instruction: required | optional`；步骤里 `off_by_default` 的（反方的「上网找」）要用户勾上才跑。
10. 估费：后面步骤要看前面结果的，按前面步骤的 `max_output_tokens` 和每条来源 1.2 万字写满来估。实际输入大约是估计的一半（见下表），确认框偏保守，不改。
11. 关系图：确定的分层布局，一份 SVG 给页面和 HTML 导出共用。
12. Markdown 和 Word 用 v0.3 的 `render::Doc` 和 `research/docx.rs`，HTML 是自己的单文件。
13. 评论来源的快照放 `数据目录/concept/sources/`，和事实调查分开，不会被调查的清理删掉；网页下载没开「失败改用 Claude 网页抓取」。
14. Word 引文：有页码的 label `page`、locator `110 (I.i.3)`（APA「p. 110 (I.i.3)」、GB/T 顺序编码「[1]110 (I.i.3)」）；没有页码的 label `paragraph`、locator `I.i.3`。原文放在引文数据的 `pithQuote` 里。

## 本地改的

1. **Word 里插入原文**：桥接（`word/bridge.rs`）在搜索窗交回的引文带 `pithQuote` 时多回一行 `Q\t<原文>`（空白合成一个空格）；宏（`Pith.bas`）只在新插入引文时把「“原文”」插在引文控件前面，编辑已有引文不插；刷新失败时连插入的原文一起删掉。测试 `pick_card_quote_adds_a_quote_line`；用新宏生成模板（`docx-engine dotm`）通过。在 Word 里点一遍等用户装好 0.4.0 后做（下文）。
2. **段落检索的排序**（真实数据里看到的）：原来每个词只取前 `limit` 条，再丢掉映射不回原著的（中译的命中很多在导读、注释、没对齐的章里），最后按书里的顺序截断——「市场」在 8 条里只剩 1 条（I.iii.3）。改成每个词多取（`limit × 8`），按相关度留前 `limit` 条，再按书里的顺序排：「市场」得到 I.iii.1、I.iii.3、I.iv.16 等 6 条。

4. 导出里的时间写成「2026-11-13 09:22 UTC」（原来是 ISO 原样）。
5. clippy 提示（云端的 2 条和本地测试里的 1 条）。
6. **真实验收的测试** `real_concept_run`（默认忽略）：和 App 走同一条路（`run_prepare` 出确认框 → `run_create` → `execute_now`），为此把两个命令的主体抽成不依赖 Tauri 的函数（行为不变）。分 books / pdf / run / search / export / quotes 几步，用法见 `docs/testing.md`「概念研究」。

## 已知问题、没做的

- **重新解析**没做：再解析一次是存成第二份文本，旧卡片不会按引文重新找锚点。
- **全书对齐**只保证了第一篇第 1–3 章（云端统计 35 章里 16 章段数不同）；Penguin 第二册的编者「Introduction」被认成了正文单元。中文版几个篇名单元下有少量段落被算成正文。英文版书前的作者简介等也被算成正文（单元 `U1`）。
- 「问这本书」的本地检索按词，长问句要拆关键词，没有语义检索；页面上可以改检索词。
- GB/T 7714 著者-出版年制这份 CSL 样式在引文里本来就不出定位（「(Smith, 1999)」），要页码 / 段落号用顺序编码制或 APA。
- 每次打开研究都从库里读整本书（约 6000 段），没测时间。
- 概念研究的网页下载没开「失败改用 Claude 网页抓取」。
- 确认框的估计偏保守（实际输入约是估计的一半）。
- 反方：每个来源只发正文的前 1.2 万字，长文章里真正的评论可能在后面，这次三个来源只出了一张评论卡；以后可以按检索词挑段落再发。
- 本地检索按 bm25 取前几条，「市场」取 6 条时 I.iii.1（本章主旨）排在第 7；页面上可以多列一些让用户勾。
