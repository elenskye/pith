# 0017 · v0.2 W2 引用：工程上的做法

- 日期：2026-11-10
- 状态：已定（工程选择，可逆，按 `CLAUDE.md` 规则 3 直接定。用户 ASK 同意过「让访达代为复制模板」，实测行不通，改成第 7 条的做法，见下）
- 依据：`0006`（数据格式与接入路线）、`0015`（v0.2 开工前的选择）、`0016`（W1 入口）

## 定下的

1. **置顶搜索窗**（`word/picker.rs`、`src/picker/Picker.tsx`）：Word 里点 Add/Edit Citation → 宏发 `pick`（带光标所在引文的 ID 与数据部件）→ Pith 弹一个置顶的小窗（与主窗口同一份前端，`?window=picker`），Word 的请求一直等到选完或取消（最多 14 分钟）。
   - 选文献：输入即搜（文献库的搜索，不含回收站；空搜索给最近加入的），回车加入；每条可填页码；回车 / ⌘回车插入，Esc 取消，关窗等于取消。
   - 光标在 Pith 引文里（或选中了正好一处引文——点控件的标题会整个选中它，实测发现）：预填这处引文的文献与页码（文献库里没有的用文档快照显示），可增删、改页码，或「删除这处引文」。同一个引文 ID 写回，保留创建时间。
   - 打开时经启动服务打开 Pith 自己的 .app，把 Pith 切到前台（macOS 14 起后台 App 不能自己抢焦点，只 `set_focus` 时窗口出来了但键盘还在 Word——实测发现）；选完把窗口藏起来，用 `open -b com.microsoft.Word` 把 Word 切回前台。两者都不需要控制别的 App 的权限。只有搜索窗到前面，Pith 主窗口不跟着出来。窗口第一次用时才建，之后只是藏起来。
2. **样式**：清单 = 内置（`src/cite/styles.json`，加了 `uri` = CSL 文件里的 `<id>`）+ 导入的 .csl（`数据目录/styles/`）。导入样式的 ID 就是它的 CSL `<id>`（与 Zotero 文档设置里记的一致）。
   - 导入：检查是 CSL 1.0 样式（有 id、title、citation；脚注样式暂不支持）、不与内置重复；依赖样式的母样式必须是内置的或已导入的；复制进数据目录后用合成文献试排一次，排不出来就恢复原样。
   - Word 里切换：选项卡上的 Style 是 `dynamicMenu`，每次打开问 Pith 要清单（英文名；导入的用它自己的标题），当前样式打勾；选了就带着样式刷新整篇。
3. **GB/T 7714 顺序编码的引文页码「[2]17」**：官方 CSL 不输出引文页码。不改 CSL 文件，在排版器（`src/cite/engine.ts`）里补一条规则，样式清单里标 `locator: after-brackets`（2015、2025 两个顺序编码）：有页码的引文，编号用 citeproc 自己排的（与书目一致），页码放在方括号外；一处引文多条文献时，没页码的照常合在一个方括号里（3 个以上连续用连接号），有页码的各自「[n]页码」，按编号排、用「,」连。
4. **中文姓名**：分成姓、名两栏的中日韩姓名，交给排版器前合成一个全名（`plan::for_render`），APA、Chicago、GB/T 著者-出版年的正文引文出「王晓明」而不是「王」；书目本来就是姓名连写，不变；文档快照与文献库数据不变。
5. **文献 → CSL-JSON 与 Zotero 对齐**（真实论文逐字段比对后补的，`word/csl.rs`）：
   - 有页码的期刊、报纸、杂志文章不出网址与访问日期（Zotero 偏好 `export.citePaperJournalArticleURL` 默认关的做法）；
   - 「额外」字段里「Volume: 46」「Original Date: 1776」这类行换成 CSL 变量名（`volume: 46`），citeproc 才认；
   - `rights` → `license`。
6. **Zotero 引文转换**（`docx_engine::cite::zotero`、`convert`）：
   - 识别：`ADDIN ZOTERO_ITEM CSL_CITATION {json}`（也认早期的 `ADDIN ZOTERO_ITEM {json}`）、`ADDIN ZOTERO_BIBL`；样式从自定义文档属性 `ZOTERO_PREF_1`、`_2`… 拼出来读。
   - 对应：每条文献按 Zotero 条目 key（URI 末段）找文献库里 `source = 'zotero'` 的条目（个人库优先、不在回收站的优先）；找不到的用域里自带的 itemData 做文档快照（ID `zotero-u-<key>`），引文照样能排、能刷新；页码、前后缀、不显示作者原样带过来；手改过文字的（dontUpdate / custom）报告后按样式重排。
   - 样式：文档已有 Pith 数据就沿用；否则按 Zotero 样式 URI 对应内置或导入的样式；对不上用默认 GB/T 并说明。
   - **Word 里**（Convert Zotero 按钮）：宏收集正文的 Zotero 域代码发给 Pith，Pith 给每个能换的域一个新引文 ID 和数据部件；宏从后往前把域 Unlink 后包成引文控件，书目域换成书目控件，存数据部件，再刷新一次。可以用 Word 的撤销退回。
   - **Word 外**（设置 › 转换 Zotero 文档；服务 `/v1/docx/convert-zotero`）：直接改 .docx 写新文件「原名（Pith）.docx」，原文件不动。写完独立核对：Zotero 域以外的正文文字、别的域、其他部件都没变（书目紧挨着的段落分隔不算），转换的域变成控件、没转换的原样，引文与书目就是计划里的样子；不通过不交付。报告逐处比较 Zotero 原来显示的文字与 Pith 排出的。
   - 没把握的结构一律不动、只报告：域伸进别的元素、域里有修订、首尾不全在域里的书签、读不懂的代码；脚注里的 Zotero 引文（脚注样式）不转换。
7. **安装：用户在「打开」对话框里选中 Word 启动文件夹**：macOS（App 数据保护）不让 Pith 写 Office 的组容器；请访达代写也不行——用户允许 Pith 控制访达后，访达找得到文件夹，但复制时报 -5000「没有权限」（macOS 把访达这次操作算在 Pith 头上，2026-11-10 实测）。macOS 认用户本人的动作，所以：Pith 写不进去时，模板先存进数据目录，设置页打开一个已经指向启动文件夹的对话框，用户点「打开」，Pith 写进去（`install::install_into`，只认 Office 组容器里叫 Word 的文件夹）。实测选过一次之后，之后的「更新」直接写得进去，不再弹对话框。手动拖放的步骤仍然留着。访达的做法删掉了（白要一次控制访达的权限）。
8. **选项卡**：Add/Edit Citation、Bibliography、Refresh｜Style（菜单）、Convert Zotero｜Open Pith。图标用 lucide 图标生成的 PNG（`scripts/word-icons.mjs` + `.swift`，64px），打包进模板的 `customUI/images`（Mac Word 不认 `imageMso="Bibliography"`，Zotero 的模板也是自带图片）。
9. **在 Node 里跑排版器**（`docx_engine::cite::node`、`scripts/cite-render.ts`）：与 App 的 WebView 同一份 `src/cite/engine.ts`，给真实数据测试与命令行用，不用开 App。

## 真实 Word 实测（Word 16.114.4，2026-11-10）

测试用 Pith 0.2.0（数据在临时目录 = Zotero 副本导入的 88 条），论文是终稿的副本：

- 安装：Pith 写不进启动文件夹 → 对话框已打开那个文件夹 → 点「打开」→ 装好；之后「更新」直接写入。选项卡 6 个按钮 / 菜单，图标都显示（Style 是下拉菜单）。
- Convert Zotero：63/63 处转换，87 条文献全部对应到文献库，样式 GB/T 7714-2015 顺序编码；Word 存盘后服务的独立核对一致（63 处引文、61 条书目，Zotero 域 0 个）。
- Add/Edit Citation：搜索窗弹出、输入即搜、回车加入、回车插入；插入「[4]17」后后面的编号整体后移；编辑这处引文（加一条文献）→「[4]17,[5]」；「删除这处引文」后编号复原。
- Style：菜单列出 5 个样式、当前的打勾；切 APA → 作者-年份格式、页码「p. 17」、中文作者出全名；切回 GB/T 一致。书目悬挂缩进、沿用论文的字体与行距。
- 最后 Word 存下的文档核对通过（64 处引文、61 条书目）。
- 测完：恢复了用户原来的桥接脚本（连 `~/Pith`）；启动文件夹里留的是 W2 的模板。

实测发现并修了：访达复制行不通（改成对话框）；搜索窗拿不到键盘（改成经启动服务切到前台）；整个选中的引文认不出来（宏里多认一种情况）。另：用自动化点 Word 选项卡时，紧跟在别处点击之后的一下会被 Word 忽略（要先移动鼠标），真人操作不受影响。

## 不选

| 方案 | 原因 |
| --- | --- |
| 请访达代为复制模板（用户同意过） | 实测访达报 -5000「没有权限」，macOS 不让别的 App 借访达写 Office 的组容器 |
| 改官方 GB/T CSL 文件加页码 | CSL 里方括号是整处引文的前后缀，页码放不到括号外又保住「[1-3]」合并；改了还要维护分叉 |
| 样式菜单用固定清单写进模板 | 导入的样式进不去，每次导入都要重新生成、重新装模板 |
| Word 里用 InputBox 输编号选样式 | 难用；dynamicMenu 是选项卡原生的 |
| 搜索窗用 Word 的 UserForm | 生成 VBA 工程要写窗体设计器的二进制；搜索要连文献库，不如直接在 Pith 里做 |
| Zotero 转换只做 Word 外 | 用户在 Word 里打开着论文时最顺手的是一个按钮；Word 外这条路留给批量、验收与「不动原文件」 |
| 找不到的文献按 DOI / 标题模糊对应 | 要求按 Zotero 条目 key；模糊对应可能对错，宁可用文档自带的数据 |

## 后果

- 宏协议多了 `pick`（编辑）、`styles`、`zotero`；Host 去掉了 W1 的测试引文。改宏要重新安装模板。
- 文档里的数据格式没变（`urn:pith:citations:v1`），W1 插的引文照常刷新、编辑。
- 用户数据里有 7 个英文作者是单栏姓名（「姓, 名」或「名 姓」写在一栏），GB/T 要「姓大写 + 名缩写」、APA 只出姓，需要在 Pith 里把作者改成姓、名两栏（Zotero 原来的输出也一样带这个问题）。
