## 用户定的

1. **排版 Agent 的模型**：Claude Opus 5.5（`claude-opus-5-5`，每百万 token 输入 $4 / 输出 $20），走 Anthropic API。月预算硬上限默认 **$20**（`0004` 的 $10–50 内），设置里可改，超限拒绝调用；密钥存钥匙串。
2. **论文发给模型的程度**：W3 做两种模式，用两份真实论文各跑一轮，比较排版计划的质量与费用后再定默认：
   - 结构和片段：样式、标题、每段开头若干字、题注与表格的位置，不发整篇正文；
   - 全文。
   学校规范、模板等要求文档整份发送。
3. **顺序**：W1 入口 → **W2 引用** → W3 排版 Agent → W4 结构类排版 → W5 验收。
4. **v0.1 阅读器错位**（0.1.1 修复）之前画的高亮 / 下划线：位置存偏了，用户自己删了重画，不做自动校正。

## 工程上直接定的

- **本机服务**：在 Pith 主程序里，只监听 127.0.0.1，随机端口 + 令牌，写进数据目录的 `service.json` 供宏读取。Word 里点按钮时 Pith 没开，就在后台启动它（`open -g`）；不常驻、不开机自启。
- **宏怎么调服务**：沿用 `0006` 的 AppleScriptTask（脚本放 Word 的 Application Scripts 目录），由脚本请求本机服务；宏本身不起 Node。
- **插入引文的搜索框**：Pith 弹一个置顶的小搜索窗（类似 Zotero 的快速搜索条），按 App 规则用中文；Word 里的选项卡、按钮、宏对话框仍是英文（`0006`）。
- **全局模板（.dotm）**：Pith 设置里一键装进 Word 启动文件夹、一键卸载；写不进去就打开那个文件夹并给出手动步骤。
- **样式**：内置 GB/T 7714-2015 顺序编码制（学校要求）与著者-出版年制、APA 7、Chicago 著者-日期；也可以导入任意 `.csl` 文件。
- **Word 里的引文数据格式**沿用 `0006`（内容控件 + Custom XML，命名空间暂用 `urn:research-lab:citations:v1`）；W1 移植时定是否改名，改名就同时读旧名。
- **版本号**：W1 开工时改为 0.2.0（`package.json`、`src-tauri/Cargo.toml`、`tauri.conf.json`）。
