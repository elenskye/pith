## 采纳的工程选择（云端定的）

细节见 `docs/architecture.md`「v0.3 事实调查」。

1. 引擎（`crates/research-engine`）和 App 分开；`Run` 整份可序列化，每次保存在一个事务里整份换掉这次调查的行。
2. 核对两层：流程里核一次，`audit` 对存下来的结果和快照从头再核一遍；`research_run_get` 每次都审计做完的调查。
3. 数字只由代码写进结论：占位符 + 逐个核对模型自己写的数；计算用精确十进制。
4. 带网页搜索的请求不加结构化输出（下面核对过：官方文档说网页搜索的引用总是开着，引用和 `output_config.format` 不能同时用）。
5. Claude 网页搜索当检索接口时关掉动态过滤（`allowed_callers: ["direct"]`，官方文档的写法）；计划时摸底用默认（动态过滤）。
6. 费用宁多勿少：发送前按最坏情况查月上限；缓存命中按原价记；没给用量的按估计记并标出。
7. 下载不碰本机和内网地址，跳转自己跟、每一跳都查，类型按内容判断。
8. 默认：计划 / 结论 `claude-opus-5-5`（effort high），摘证据 `deepseek-flash`，检索 Tavily 基础搜索，计划时最多 3 次 Claude 网页搜索摸底；量的上限 12 个子问题、每个 3 个搜索词、每次 5 条结果、40 个来源。
9. Word 导出不改文档引擎（用 `Package` 拼最小的 .docx）。
10. 前端 mock 数据由引擎生成（命令见 `docs/testing.md`）。

## 本地改的

1. **DeepSeek 关掉思考**：请求带 `thinking: {type: "disabled"}`（只对 DeepSeek 的地址或模型名带；别的 OpenAI 兼容接口不一定认这个字段）。思考的 token 算输出、占 `max_tokens`，摘证据用不着；`finish_reason: aborted` 当失败处理。
2. **结论里单位写两遍**（真实调查里看到的）：模型写「高 {C1}个百分点」，代码换上的值已经带「个百分点」，读成「26.8 个百分点〔C1〕个百分点」。修法：
   - 提示词写明换上去的值带着单位；
   - 代码去掉占位符后面紧跟着的同一个单位（`conclude::drop_repeated_units`）；
   - 修之前存下的调查，读出来时同样处理，审计也先这样处理再比较，所以不会被误报成「改过」。
3. **Mac 上一项测试失败**：`transfer::tests::edited_or_foreign_exports_are_refused` 把导出的 JSON 按字节对半截断，云端在样本库里加了中文以后，切点可能落在一个字中间（和临时目录路径的长度有关，Linux 上碰巧没落中）。改成退到字符边界。
4. **侧栏**：已经在排版 / 调查页时再点侧栏的这一项，回到它的列表（从设置回来时仍停在原处）。
5. **重查对比的对齐**（真实重查里看到的）：同一条事实两次写成「城镇调查失业率年度均值」「年平均值」、「北京市」「北京」，按文字键对不上，新查到 / 没再查到各 220 多条，大半是这种。加第二遍对齐（`diff::same_slot`）：地区去掉「市」「省」、时间里的数字、人群里的数字（年龄段）都一样，指标名的二字组相似度 ≥ 0.6、数值相同 → 没变；相似度 ≥ 0.8、数据生产者相同、数值不同 → 变了。「登记失业率」和「调查失业率」、不同年龄段不会被对到一起（有测试）。同一份数据重新导出：新查到 229 → 140、没再查到 223 → 134。
6. **真实验收的测试** `real_research_run`（默认忽略）：和 App 的命令走同一套接口与设置，分拆问题 / 做完 / 重查 / 只导出几步，结果存进指定的数据目录。用法见 `docs/testing.md`。
