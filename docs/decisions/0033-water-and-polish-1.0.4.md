# 0033 · 1.0.4：整页水面回来（原生截图 + GPU），集合的小枝桠，衬线字的光学居中

- 日期：2026-11-25
- 状态：现行（补充 `0032`）
- 来源：用户 11-25「Pith v1.0.4」七条（不填问卷先优化；对齐要补向量相似度；整页要像水一样扭、不能卡；集合展开的小枝桠再打磨；带图标的按钮要悬停动效；「＋ 知识库」挪到最后、能左右滑；文字没居中）

## 定了什么

1. **整页水面**：换配色时整页像水面一样晃，这是招牌时刻（用户定）。不走 WebKit 的 SVG 滤镜（CPU 上算，`0032`），而是：
   - Rust 命令 `app_snapshot`（`src-tauri/src/snapshot.rs`）让 WKWebView `takeSnapshot`，把原始像素（宽、高、排法 + 一行接一行的像素，不编码）交给前端；
   - 前端 `app/water.ts` 把它画到一张 WebGL2 画布上盖住页面，底下换配色；着色器逐像素扭：五圈波纹按 `palette-lake` 的半径和节奏折射（高斯的导数）、整页两层低频噪声慢慢晃（和原来滤镜的 0;11;5;2;0 同一个节奏）、新颜色带着毛边跟在波纹后面洇开（圈里画布透明，露出底下真的新样子）；1.65 秒后拿掉画布。方案那层 SVG 波纹压在画布上面。
   - 外观页、⌘K 打开时先空拍一张预热（WebKit 第一次截图约 0.3 秒，之后约 50 毫秒）；⌘K 里换配色等它退场完再拍，免得把半透明的 ⌘K 拍进去。明暗切换也走这一套。
   - 拍不到（浏览器里预览、不是 macOS）或没有 WebGL 时，退回 `0032` 的 View Transitions 洇开（只洇不晃）。
2. **集合的小枝桠**（方案 `pith` 1.2.0 的 `Strip`）：展开下级时长出一根带叶的岔、底下一根茎、每个下级一颗节点、茎尽头一个珊瑚色的芽，依次长出来；收着时名字后面一个小折角。栏高固定 42px，展开不跳。
3. **悬停上墨**：一栏左右滑的胶囊（集合、生长阶段）悬停用方案的 `pith-ink`：淡底从左下滑进来，带图标的图标重描一遍。
4. **「＋ 知识库」** 跟在最后一个知识库后面，悬停一层淡底；知识库、范围那一栏鼠标竖着滚也能左右走（`useWheelX`），右边缘淡出去。
5. **衬线字的光学居中**：固定高度的胶囊、枝桠上的标签，行框往下挪 0.14em（Newsreader + 宋体后备的字形比中线高约 0.07em）。
6. **中英对齐补向量相似度**记进 `requirements.md`「以后」和 `ROADMAP.md` 1.1.0（用户定）。

## 为什么

- 实测（真 App 窗口，`VITE_PITH_PERF=water` 的开发包，1280 × 800，Retina）：拍照 44–60 毫秒、上传到 GPU 1–6 毫秒、点下去 87–112 毫秒开始动（预热前第一次 336 毫秒）；2.4 秒里 143–144 帧（满帧），没有超过 34 毫秒的帧。按时间截了窗口：300 毫秒左右整页在晃、卡片和字被波纹折弯，500 毫秒新颜色带着毛边洇开，800 毫秒只剩一角旧色。
- 第一版着色器给波峰提亮 7%，奶油纸被提成纯白，圈里一团白晕；洇开的软边 180px，扭过的旧字和底下的新字叠出重影。改成 ±2.5%、软边 56px、边缘加毛边。
- 只拍旧样子，不拍新样子：画布盖着的时候再拍，拍到的是画布自己。新样子在洇开的圈里是静的——波纹跑在洇开前面，大部分晃发生在旧样子上，看起来是「水波先过去，颜色随后洇开」。
- 居中是在 WebKit 里量的（每个按钮里字形墨迹的中心和按钮中心差多少）：衬线的胶囊、标签偏上 0.9–1.4px，Lato 的偏下 0.3px（不管）；改完胶囊都在 0.35px 内。Chrome 里同样的字偏上 1.5px 左右，两个引擎排中文后备字体不一样，所以以 WebKit 为准。
- 中英对齐：`0025` 时为了确定性只用长度和锚点，向量相似度的接口留着；做知识库检索时每段都有向量，正好一起接。

## 没做的

- 新样子那一侧不晃（见上）。要晃就得在画布盖上之前拍新样子，等于先闪一下新颜色，不做。
- R1 画布（原型）还用 SVG 滤镜。
