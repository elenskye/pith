# 0031 · 1.0.2：界面照 Explore R1 重做，技能进对话，对话和知识库先存起来

- 日期：2026-11-25
- 状态：现行
- 来源：用户 11-25「基于 Pith 目前的功能，把前端先完全做成 Explore 里面的样子，后端对应的可以先给一些框架和模拟接口」；同一天 ASK 定的两点

## 定了什么

1. **界面照 Explore R1**（Atelier `canvases/pith-explore/`，视觉在 `src/vendor/pith/`）：顶栏（Logo + 知识库、文献库、设置三个图标）、叶子首页、对话（状态行、编号和页边注、交付卡）、枝桠的对话历史、⌘K、知识库的卡片墙、文献库的表格和右边的面板、设置的枝桠和七页。R1 是 1280 × 800 的板，App 里改成跟着窗口伸缩。标题栏藏到顶栏下面（`titleBarStyle: Overlay`），顶栏能拖动窗口。
2. **事实调查、概念研究、排版进对话当技能**（用户 ASK 选的）：输入框 `/调查` `/概念` `/排版` 开一段对话，原来那套流程（确认计划、跑、结果；书架、一章、研究；规范、排版）原样放进对话里，旧流程的逻辑一行没改。以前的调查、研究在对话历史里照样列出来，点开接着问时才建对话（不写数据迁移）。三个旧页面和它们的侧栏拿掉。
3. **对话、角色、知识库真存**（用户 ASK 选的）：migration 0010 建五张表（`conversations`、`messages`、`roles`、`knowledge_bases`、`kb_materials`），只建表不改数据；加之前冻结了 v9 样本库。
   - 内置四个角色写在代码里，改过的用同一个 uid 存一份，新建的也存进去。
   - 材料先「一库一份、同一来源一库只种一次」；能种进来的是解析好的书、做完的调查、概念研究的卡片，和自己写的笔记、摘抄。共享材料、段落块和索引等 1.1.0 做检索时再改（`0030`）。
4. **回答先模拟**（`src-tauri/src/chat/mock.rs`）：不调模型、不花钱。照真回答的样子出状态行、段落、编号（指向知识库里真的材料，按问题里的字粗略地挑）、反问、交付卡，并标「演示回答」。消息的 JSON 形状就是以后真回答的形状，1.1.0 换掉模拟的那一层，前端不用改。
5. **外观**：配色（纸与海、雾与赭）和明暗（跟随系统、亮、暗）记在这台电脑上（localStorage），不进数据库。Lato、Newsreader 随 App 打包（`@fontsource`），中文用系统字体。
6. **颜色只从方案来**：原来 Tailwind 的琥珀、翠绿、蓝、紫换成从方案的金、海蓝、绯红混出来的几种语气（`src/styles/app.css`）。

## 为什么

- 技能进对话、旧流程原样搬：功能不丢，界面先到位；改写成新格式的技能、Agent 循环是 1.1.0 的事，那时换掉的只是对话里那一块。
- 先真存：对话、知识库是以后每个版本都要用的数据，早一点定下表就能早一点用起来；表照 `0030` 的分层建，模拟的只是回答。
- 一库一份先简单：多对多和段落块要和检索、索引一起设计，现在先不定死。

## 没做的

- 真的对话 Agent、技能新格式、用量圈、问题卡和任务卡的通用协议：1.1.0。
- 知识库的检索、材料共享、v0.4 的书迁成段落块：1.1.0。
- 角色名片在对话里拟、跨对话的记忆：以后。
- 文献库窄窗口时标题列会塌（以前就有）。
