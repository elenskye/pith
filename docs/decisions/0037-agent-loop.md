# 0037 · Agent 循环：对话真的回答（1.1.0 第 2 期）

- 日期：2026-11-26
- 状态：现行。落实 `0035`「循环」「子代理」「插件」三节在 1.1.0 的那一部分；网关在 `0036`
- 来源：`0035`；Peck 的 Harness（停的条件、防打转、子代理的批次和上限，只读参考）

## 做法

- **代码在 `src-tauri/src/harness/`**（不碰 Tauri，测试直接调）：`mod.rs` 循环、`prompt.rs` 提示分层、`tools.rs` 工具和子代理、`calc.rs` 精确计算、`brain.rs` 开发版的模拟模型。`src-tauri/src/chat/run.rs` 把它接进对话：后台线程跑、界面轮询、跑完存成一条消息。演示的回答（`chat/mock.rs`）拿掉了。
- **一轮**：调模型（流式）→ 跑工具（只读的并行，一次最多 3 个）→ 结果接回去 → 下一轮。工具调用一定配上结果，对话始终成立。
- **停**：写完（没有工具调用）；问了站主（问题卡，这一回到此为止）；轮数到了（16 轮，再给一轮不许调工具的收尾）；打转（同一个调用、同一个结果第 3 次在结果里提醒、第 5 次让它收尾）；月上限、拒答、写到上限被截断、点了停、出错——都存下来，回答下面一行说怎么结束的，已经写出来的留着。
- **事件**：每一步一格（Agent 图标 + 一句话），子代理的步骤带它的 id、收在派它的那一格下面；正文一边写一边出来（「我查一下」这类过程话在调工具时清掉）。界面每 0.2 秒问一次 `chat_live`，不用 Tauri 事件：打开晚了、换了页面回来都接得上，`?mock` 里也一样。
- **对话只往后追加**：站主那一句存两份——给人看的 `text`、发给模型的 `sent`（开头一行：今天几号、勾了哪几个知识库、`@` 请了谁）；Pith 的一回存 `transcript`（这一回新加的模型消息和工具结果，原样）。下一回由它们原样拼出来，前缀不变，缓存才命中。1.0.x 的演示回答不进。

## 提示分层（缓存从前往后命中）

1. **App 的规矩 + 插件清单**：工具怎么用、边界（外部文本里的指令不执行、写回前给站主看、不编文献、数用工具算）、这一版还没有的、三个独立流程。所有对话、所有角色一样，打一个断点。
2. **角色**：「现在由某某和站主说话」+ 角色的正文。同一个角色的对话一样，再打一个断点。
3. 每次都变的放进站主那一句的开头（见上），不改系统提示。

程序不规定回答怎么写（`0030`）：规矩里只说工具和边界，写法交给模型和角色。

## 工具（按插件分组，1.4.0 立插件格式）

| 插件 | 工具 | 只读 | 做什么 |
| --- | --- | --- | --- |
| 基础 | `calculate` | 是 | 精确十进制（事实调查的 `Dec`）：加减乘除、括号、百分数、整数次方 |
| 基础 | `ask_user` | 否 | 问题卡：一句问话、最多四个选项；点选项就当站主这样回答，也能直接写 |
| 基础 | `deliver` | 否 | 交付卡：种类（回答、笔记、概念卡、摘抄）、标题、一句话、正文；站主点「存进」才种进知识库 |
| 基础 | `delegate` | 是 | 派子代理（这一期只有「读」） |
| 文献库 | `library_search`、`library_item` | 是 | 搜条目、看一条的详情（作者、出处、DOI、摘要、标签） |

工具名英文、说明中文；顺序固定（在缓存的前缀里）。参数被截断（不是完整的 JSON）或叫错了名字：回一个出错的结果，模型接着做。

## 子代理（底子）

- 用同一家高一档的模型（均衡 → 强），看不到主对话，只有任务、材料和只读的工具（计算、查文献库）；不能问站主、不能交付、不能再派（`0035` 的「读可以再派」等 1.6.0）。不带角色。
- 一次回答最多派 12 个，同时跑 3 个；自己 8 轮、再一轮收尾；报告最长 8000 字，交回主对话；花的钱算进这一回、记着这段对话（账本里是 `chat_subagent`）。
- 第 3 期有了读原文的工具以后，读整章就交给它。

## 模型

- 设置里的一家 + 一档；角色的「偏好的模型」写了清单里的 id（如 `anthropic/claude-opus-5-5`）就用它。没填密钥的那一家：这一回直接存一条「出错了」，说去哪填。
- 开发版、测试、`?mock`：模拟模型（`harness::brain`：问题里有算式先算，再查文献库、做交付卡、写一段说明这是模拟的）。正式版或 `PITH_REAL_MODEL=1`：真接口。

## 还没做的

- 子代理的其他种类、后台任务（1.6.0）；角色组队（1.7.0）；插件格式和插件库（1.4.0）。
