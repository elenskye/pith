## 和引擎的关系

- **engine-pdf**：PDF 的读字（扫描件自动识别）、页码标签、目录、缩略图、Mathpix、页面操作、标注都用引擎（`../personal-engine-studio/engine-pdf`，按 tag 引用）。Pith 1.2.0 就是引擎计划里的「v0.8 接 Pith」：论文后台取字和概念研究的 Mathpix 换成引擎、阅读器换成引擎的 `EditorViewer`、删掉 `pdf-extract`。之前不再给 Pith 的 PDF 加东西。
  - **PDF 全文搜索是 Pith 的事**：引擎没有搜索接口，Pith 把引擎读出的每页文字放进自己的检索（FTS 和向量），阅读器里的页内查找用引擎套件自带的。
  - **开工前问你一件**：标注写进 PDF 文件、另存一份，还是照现在留在库里（Zotero 的格式）。改的是你的文件，所以问（`0011` 现在是 PDF 只读）。
  - 引擎的 v0.5.2 还没推到 GitHub；Pith 按 tag 引用，接之前要推上去。
- **engine-word**：做好了插一版「排版和润色」（格式规范化是你的第一件事）。之前不碰 Word 的代码；`/排版` 保持 1.0.2 搬进对话的样子，不改成插件。2.0 不等它。
- **engine-excel、engine-txt**：不等。1.3 的文本导入、1.10 的数据表先在 Pith 里写，写成独立的 crate（像 `docx-engine`），接口照引擎的样子，以后整块挪过去、Pith 这边小改。
- 一次只接一个引擎（引擎家族的规矩）。
