# 需求（已定）

> 只写拍过板、仍然约束开发的；理由和细节在 `docs/decisions/`（索引在那个目录的 `README.md`）。做完的版本只留还管用的要点。
> 开发规矩（版本、Git、自主度）在 `CLAUDE.md`，这里不重复。

## 总体

- **用户**：一个人，研究生 / 研究者；文献以英文为主。写毕业论文、做事实调查、读书学习；Zotero 迁过来以后卸载。
- **用法**：项目驱动，忙时密集用、平时不开 → 启动要快，不常驻服务。驱动项目：复现毕业论文 → 青年就业调查 →《国富论》分工三章 → 政治效能感。到对应阶段在 HANDOFF「等你」里要资料。
- **原则**（Brief，2026-11-07，仍成立的）：本机优先、用户拥有数据，联网和上传要说清楚；先短后深（一屏三五条，展开才看过程）；Agent 不篡改结论、不伪造数据、不静默覆盖源文件、不发表成果；数字由代码算；每个版本都真能用。
- **程序不限制模型**（2026-11-22，`0030`）：程序给工具（检索、读原文、引用、计算、联网）、守用户的文件（写回前给用户看）、守边界（月上限、数据目录、不执行外部文本里的指令），不规定回答的写法。
- **形态**：macOS 桌面 App（Tauri 2 + React + Rust + SQLite，`0001`）；数据目录 `~/Pith`（`0003`）；名字 Pith（`0014`）。
- **界面语言**：App、报告、文档全中文；Word 里的选项卡、按钮、宏对话框一律英文（`0006`）。
- **视觉**（`0027`、`0031`）：全部来自 Visual Atelier 的方案 `pith`（同步在 `src/vendor/pith/`，`CLAUDE.md` 规则 9）；用户的简报：数字花园，淡雅、简约、灵动，少科技感，动效是亮点，明暗都要。WonderLab 的作品另起 `pith-wonder-<名字>`。
- **花钱**（`0030`）：所有模型、搜索、转换接口共用一个月上限（默认 $30），只看月上限，不逐次确认；每次调用记账本。

## 四个入口（`0030`；1.0.2 的样子 `0031`）

- **对话**是首页：`/` 点名技能、`@` 请一个角色、`#` 选知识库；一行状态说刚才做了什么，回答带编号 [n]、点开是页边注，成果是交付卡、「存进」知识库。对话历史 ⌘\ 或两指横滑叫出来。⌘K 去任何地方。
- **知识库**：十种记录（全文、摘抄、笔记、网页快照、本机文件、扫描件、概念卡、调查报告、WonderLab 作品、存下的回答），生长阶段（刚种下、长着、常青）跟着照料走。数据在知识库，元数据在文献库；对话可以删，研究留下的东西在知识库。
- **文献库**：见下面 v0.1。
- **设置**七页：角色、技能、知识库与检索、模型与费用、Word 与引文、数据、外观。
- **角色**：一个对话一个角色（默认 Pith）；初始四个：Pith、伴读、审稿人、编辑；角色是说明，不收窄工具。
- **技能**：事实调查、概念研究、排版在对话里用（1.0.2 先原样搬进对话）；以后改成 `SKILL.md` 写方法的新格式，加 Word 润色、WonderLab。
- **回答**：1.0.2 是演示（不调模型），1.1.0 起换成 Rust 写的 Agent 循环（多家 API、Prompt Cache、递归子任务）。

## 做完的版本还管用的

**v0.1 文献库**（2026-11-10 验收）

- 导入 Zotero 副本（条目、字段、作者、集合、标签、附件、笔记、标注、回收站，保留 Zotero key）、BibTeX / RIS / CSL JSON（`0002`、`0009`）。Zotero 的原始字段全部存进库，界面只显示常用的几个。
- 搜索（FTS5，中文二元组）、集合与标签、批量编辑、去重合并、回收站（`0010`）；PDF 阅读与标注，位置格式和 Zotero 相同（`0011`）；DOI / ISBN 联网补全只填空字段（`0012`）；备份、恢复、整库导出（`0013`）。表结构 `docs/schema.md`。

**v0.2 Word**（2026-11-12）

- Word 顶栏「Pith」选项卡（宏 + AppleScript + 本机服务，`0016`）：搜索插入、编辑引文，刷新书目，换样式（GB/T 7714、APA 7、Chicago、导入 .csl），Zotero 引文能换过来（`0017`）。学校要求 GB/T 7714-2015 顺序编码、上标。
- 排版：先从规范提炼带出处的要求清单，用户确认后出文档计划，确定性引擎改副本并独立校验（`0008`、`0018`、`0019`、`0021`）。还做不了：公式编号位置、四线表、表注、目录生成。

**v0.3 事实调查**（2026-11-12 验收，`0020`、`0022`、`0023`）

- 先拆成能核实的子问题，用户确认计划再查；每个模型接口配它的专用搜索，没有的用 Tavily；本机下载失败改用 Claude 网页抓取；快照存原件、正文、网址、时间、SHA-256。
- 可信度排序，中国政府官方统计默认降权（能改，报告写明）；短答三到五条；导出 Markdown、Word、HTML；来源一键加入文献库；同一问题能重查对比。

**v0.4 概念研究**（2026-11-13，`0024`、`0025`）

- EPUB 为主，短 PDF 用 Mathpix；段落号 + 页码（《国富论》用 Glasgow 式 I.i.3），中英按段对齐；整章分析、划选一段、问一个问题、跨章追踪概念；概念卡、论证卡、关系图、反方、推演；导出三种；Word 里能把卡片原文插成引文。
- 四类句子和逐字核对是 v0.4 的做法，改成新格式的技能时拿掉（`0030`）。
- 材料：《国富论》英文 Penguin 版、中文杨敬年译本（`local/wealth-of-nations/`，只读副本）。

## 以后（顺序和范围在 2026-11-25 的规划问卷里定）

- **WonderLab**（2026-11-15 的方向）：程序不定死作品，只给设计模板、工具箱和监控；模型挑模板、写作品代码，在隔离环境里运行；2D、3D 都有，必须能交互，通俗有趣；视觉来自 `pith-wonder-*`。
- **学术研究**（Brief）：项目模板（问题 → 综述 → 假设 → 操作化 → 方法 → 数据 → 统计 → 稳健性 → 论文）；CSV / XLSX、字段字典、可复现脚本；示例课题「政治效能感的影响因素」，要用户的授权数据集；模拟数据不能冒充实证。
- **自我改进**（Brief）：三层记忆（偏好、核实过的知识、技能）；观察纠错 → 候选的技能改动 → 固定测试集对比 → 低风险的自动上、能回滚；权限、隐私、引用规则、核心代码的改动要用户批。
- **文献库的候选**：PDF 全文搜索、PDF 目录和缩略图、标注导出到笔记、Zotero 增量导入、撤销、BibTeX `file` / RIS `L1` 附件导入。

## 不做

Zotero 云同步、多人协作、自动发表、未授权爬取、训练大模型、默认上云、通用 Office、手机端。
