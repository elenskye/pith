# 需求（已定）

> 只写已经拍板的；细节和理由在 `docs/decisions/`，原始设想在 `docs/brief-digest.md`。来源：三轮问卷（`docs/questionnaire/`）、ASK 确认、各期验收反馈。
> 做完的版本只留仍然约束后续开发的要点。

## 总体

- 用户：一个人，研究生 / 研究者；文献以英文为主。
- 用途：写毕业论文、日常事实调查、读书学习；把 Zotero 迁移过来后卸载 Zotero。
- 使用方式：项目驱动，忙时密集用、平时不开 → 启动要快，不常驻服务。
- 驱动项目：复现毕业论文（v0.2）→ 北京、天津青年就业（v0.3）→《国富论》分工三章（v0.4–0.5）→ 政治效能感（v0.6）。到对应阶段在 HANDOFF「等你」里提醒用户提供资料。
- 形态与栈 `decisions/0001`；数据目录 `0003`；LLM 与联网 `0004`；版本顺序 `0005`。
- **界面语言**：App、报告、文档全中文；Word 里的选项卡、按钮、宏对话框一律英文（`0006`）。
- **视觉**：v0.7 之前各版本只求简约；视觉设计与 Visual Atelier 联动放到 v0.7 之后（`0005`，2026-11-12）。
- **花钱**：所有模型、搜索、转换接口共用一个月上限（默认 $30）；每次发送前列出要发的内容和预计费用，用户确认才发；完成后显示实际费用，都记进账本（`0018`、`0020`）。

## v0.1 Library（已验收 2026-11-10）

- 导入：Zotero 副本（条目、字段、作者、集合、标签、附件、笔记、标注、回收站，保留 Zotero key）、BibTeX / RIS / CSL JSON（`0009`）。
- **字段原则**：Zotero 的全部原始字段都存进库（`item_fields`），不丢；界面只显示常用的少数几个，其余收起。
- 搜索（FTS5，中文二元组，`0010`）、集合与标签、批量编辑、去重合并、回收站。
- PDF 阅读与标注，位置格式与 Zotero 相同（`0011`）；DOI / ISBN 联网补全，只自动填空字段（`0012`）。
- 备份、恢复、整库导出（`0013`）。数据模型见 `docs/schema.md`。
- 留到 v0.1.x、用户提出时插队：PDF 全文搜索、Zotero 增量导入、撤销系统等（`ROADMAP.md`）。

## v0.2 Word Studio（已完成 2026-11-12）

- 接入：Word 顶栏「Pith」选项卡（宏 + AppleScript + 本机服务），Office.js 代码保留待用（`0006`、`0016`）。
- 引用：Word 里搜索插入、编辑、删除引文，刷新书目，切换样式（GB/T 7714 顺序编码 / 著者-出版年、APA 7、Chicago、导入 .csl）；Zotero 引文能转换（`0017`）。学校要求 GB/T 7714-2015 顺序编码、上标，著录规则见 `local/real-thesis/cqu-requirements.md` F 节。
- 排版 Agent：Opus 5.5；先从规范提炼带出处的要求清单，用户确认后生成文档计划，由确定性引擎改副本并独立校验，不通过不交付；论文默认按「结构和片段」发送（`0008`、`0018`）。结构类排版见 `0019`，Word 里验收修的问题见 `0021`。
- 还做不了、写进报告的：公式编号位置、四线表、表注、目录生成。

## v0.3 Fact Research（已验收 2026-11-12，`0020`、`0022`、`0023`）

- 什么问题都能问：先拆成可核实的子问题，用户确认计划后再执行。
- 检索：每个模型接口配它的专用搜索（Anthropic → Claude 网页搜索），没有的用 Tavily；也能手动加网址或文件。本机下载只取单页，失败了改用 Claude 网页抓取。
- 快照：原件 + 正文 + 网址、抓取时间、SHA-256。
- 摘录和数字由代码逐字核对，计算由代码做；核不上的不进结论。
- 可信度：不限来源、按可信度排序；中国政府官方统计默认降权（设置里可改，报告写明）。
- 结论：Opus 5.5 写 3–5 条短答，每个数字对得上已核实的事实，标出不确定的类型。
- 报告短答在前；导出 Markdown、Word、单文件 HTML；来源可一键加入文献库；同一问题可重查对比。
- 模型：计划与结论 Opus 5.5，摘证据 DeepSeek `deepseek-flash`。

## v0.4 Concept Research（2026-11-13 第三轮问卷，`decisions/0024`）

| # | 功能 | 备注 |
| --- | --- | --- |
| C1 | 读书 | EPUB 为主；短的 PDF（新闻、短文）用 Mathpix 转文字。书是文献库里的一条文献，原著和译本各一条 |
| C2 | 原文定位 | 段落号 + 页码（有页码的版本才给）；《国富论》用 Glasgow 式段落号（I.i.3），中英按段落对齐 |
| C3 | 技能与工作流 | 不定死产出：技能（`SKILL.md`）声明做法和步骤，常用场景做成内置技能；用户可以放自己的技能 |
| C4 | 产出 | 概念卡、论证卡、关系图、反方与后世评论、假设推演、笔记 |
| C5 | 三类内容 | 原文说的 / AI 解释的 / 假设推演的，另有「他人」（有出处的评论、译者注）。原文逐字核对；解释尽量挂原文，挂不上的照样显示并标明；推演单独一类 |
| C6 | 入口 | 整章分析、划选一段、问一个问题、跨章追踪一个概念 |
| C7 | 反方 | 先查文献库，不够再用 v0.3 的检索，都要有出处 |
| C8 | 页面 | 第四个主页面「概念」，侧栏书 → 章 → 卡片；原文段落直接显示（带段落号），划选即可分析；不做完整 EPUB 阅读器 |
| C9 | 导出与引用 | Markdown、Word、单文件 HTML（关系图能点）；Word 里能把卡片原文插成引文（带页码或段落号） |
| C10 | 模型与费用 | GPT-6.1 Sol（OpenAI Responses API）；共用月上限 $30；每次发送前确认 |

**材料**：英文 Penguin 版（Skinner 编）、中文杨敬年译本（陕西人民 2011），用户提供的 EPUB，副本在 `local/wealth-of-nations/`；云端测试另用 Cannan 版（公有领域）+ 合成中文。

**验收**：分工三章（中英对照）概念卡 ≥ 15、论证卡 ≥ 5、一张关系图；每句原文引用逐字核对通过；三类内容标得清楚；用户抽查 10 张，觉得准确、对复习有用。其余标准见 `0024`。

**不做**：完整 EPUB 阅读器、手动对齐、App 里的技能编辑器、长书走 PDF、中文页码。
