## A · 读哪个本子

**A1. 用哪个版本？**

- 英文原著：Glasgow 版（Oxford 1976；Liberty Fund 重印）
- 英文原著：Cannan 版（1904）
- 中译本：杨敬年译（陕西人民出版社）
- 其他：我会提供给你中译本和英文原著各一个 EPUB，需要你查看是否可用，如果英文原著的 EPUB 不好用，你就直接从网上下载 Cannan 版的

**A2. 给 Pith 的文件用什么格式？**

- 其他：EPUB 为主。但 Concept Research 也要能解析、分析 PDF，可以调用 Mathpix API（我来提供），比如有些新闻、短篇，PDF 就更好

**A3. 卡片里引用原文时，用什么定位？**

- 两样都给
- 补充：国富论这种超长文默认 EPUB，PDF 的处理局限于篇幅不多的

**A4. v0.4 做多大范围？**

- 只做分工三章（第一篇第 1–3 章），先做扎实

## B · 概念研究做出什么

**B1. 要做出哪些东西？**

- 概念卡
- 论证卡
- 关系图
- 反方与后世评论
- 其他：不用完全定死，这是一个 Agent 功能，原则上可以做出任何效果，只不过要做好 SKILL、工作流，以及常用的场景也可以做成 SKILL

**B2. 「AI 解释的」内容，要不要也挂原文？**

- 尽量挂，挂不上的照样显示，但标明

**B3. 「假设推演」（例如「如果市场范围扩大十倍，分工会怎样」）v0.4 要不要做？**

- 要，单独一类，标清楚是推演、不是原著观点

**B4. 反方和后世评论从哪来？**

- 先查你的文献库，不够再用 v0.3 的检索找有出处的

**B5. 从哪里开始一次概念研究？**

- 选一章，整章分析
- 选一段原文（读的时候划选）
- 问一个问题
- 选一个概念，跨章节追踪

**B6. 主要拿来做什么？**

- 自己读懂、复习
- 写文章或论文时引用
- 讲给别人听，或做成知识作品（接 v0.5 WonderLab）

## C · 放在 Pith 的哪里

**C1. 页面怎么放？**

- 左边一列加第四个主页面「概念」，侧栏是书 → 章 → 卡片

**C2. 原文怎么看？**

- 概念页里直接显示原文段落（带段落号），划选就能生成卡片

**C3. 书跟文献库的关系？**

- 书作为一条文献（带 EPUB / PDF 附件），卡片引原文就是引这条文献

**C4. 要能导出成什么？**

- Markdown
- Word（用 v0.2 的文档引擎）
- 网页（单个 HTML，关系图能点）

**C5. 在 Word 里写作时，要不要能把卡片里的原文插成引文（带段落号或页码）？**

- 要，v0.4 就接上 v0.2 的引用引擎
