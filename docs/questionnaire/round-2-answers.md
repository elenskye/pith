## B · v0.3 要回答什么

**B1. 事实调查做多宽？**

- 通用：什么事实问题都能问，用就业问题验收

**B2. 关于「不同城市真实就业情况」，你最想弄清的是哪种？**

- 几座城市的官方数字能不能直接比
- 官方数字和其他来源对不上时，哪个更接近真实
- 某一类人的情况
- 给自己找工作、选城市做参考

**B3. 具体是哪几座城市、哪类人、哪段时间？**

> 2022～2026 年，北京、天津的年轻人（应届生和非应届生）就业情况，同时与其他一线城市、热门二线城市进行对比

**B4. 想看哪些指标？**

- 青年（16–24 岁）失业率
- 平均工资（非私营 / 私营单位）
- 岗位数与求职人数之比（求人倍率）
- 灵活就业、平台就业
- 其他：国家统计局和政府官方数据存在造假、偏差嫌疑，想办法找到更加客观的数据和衡量维度。事实研究板块，"中国政府"的官方数据的权重要降到比较低

**B5. 来源怎么取舍？**

- 不限来源，按可信度排序
- 补充：事实研究板块，"中国政府"的官方数据的权重要降到比较低，中国的统计局和人社局都不太值得信任

**B6. 结果默认怎么呈现？**

- 先给短答，展开才看全过程

**B7. 要能导出成什么？**

- Markdown
- Word（.docx，用 v0.2 的文档引擎生成）
- 网页（单个 HTML 文件）

**B8. 调查里用到的网页、公报，要不要能存进文献库？**

- 能，结论页上一键加入文献库
