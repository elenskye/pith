## A · 你与使用场景

**Q1. 未来 3 个月你会把 Research Lab 用在哪些事上？**

- 写毕业论文 / 学术论文（Library + Word Studio + Academic）
- 日常事实调查，如政策、城市数据、跨境转账路径（Fact Research）
- 读书与长期学习，把摘抄变成概念卡 / 图表（Concept + WonderLab）
- 其他：把 Zotero 的数据迁移过来，然后卸载 Zotero

**Q2. 如果只能先解决一个痛点，你选哪个？**

- Zotero 文献管理不顺手，想要自己的 Library

**Q3. 你手头有没有一个真实的、马上要用的项目来驱动开发？**

- 其他：三个可以拿来驱动项目：复现我的毕业论文 / 国富论阅读 / 不同城市的真实就业情况，开发到对应阶段时，提醒我提供必要资料

**Q4. 你的文献主要是什么语言？**

- 英文为主

**Q5. 预期使用频率？**

- 项目驱动，忙的时候密集用，平时不开

## B · 项目大方向

**Q6. v0.1 的产品形态？**

- macOS 桌面 App（Tauri 2 + React + TS，Brief 首选）

**Q7. 给 Brief 中 7 个模块打优先级**

- Library（文献与资料库）：1
- Word Studio · 引用引擎（Word 插件动态引用）：1
- Word Studio · 排版 Agent（自然语言 → 格式规则）：1
- Fact Research（事实调查）：2

- Academic Research（专业研究 + 统计）：5
- WonderLab（可视化与复习）：4
- Adaptive Agent（记忆 / Skills / 自改进）：5

## C · v0.1 Library 详细计划

**Q13. v0.1 必须包含哪些功能？**

- Zotero 库导入（只读）
- BibTeX / CSL JSON / RIS 文件导入
- DOI / ISBN 输入后自动补元数据（需联网）
- PDF 附件管理（复制到自己的存储，保留哈希）
- 全文搜索（标题 / 作者 / 标签 / 摘要，SQLite FTS5）
- 标签与分类（集合 / 文件夹）
- 内置 PDF 阅读器
- PDF 高亮 / 摘录并保存精确锚点（页码 + 坐标）
- 去重提示
- 批量编辑元数据
- 备份 / 恢复（整库导出为一个目录或压缩包）
- 中文界面

**Q14. PDF 阅读方式？**

- 内置阅读器（pdf.js），支持高亮摘录

**Q15. Zotero 导入走哪条路？**

- 直接读 zotero.sqlite 的只读副本

**Q16. 测试数据怎么来？**

- 其他：我可以提供真实 Zotero 库的一份副本（放到项目外的指定目录），但你要告诉我怎么导出副本

**Q17. 你的 Zotero 库大约多大？**

- 100 – 500 条
- 补充：其实我也不太清楚，之后你可以通过导出的副本判断

**Q18. 数据存放位置？**

- 其他： ~/ResearchLab/ 一个目录装下 SQLite + 附件 + 备份（和 Pomelo 差不多的设计）

**Q19. 核心数据层用什么语言写？**

**Q20. UI 风格参考？**

**Q21. v0.1 的验收标准？**

- 用真实库副本迁移后，我日常用 1 周没有丢数据 / 没有想回 Zotero
